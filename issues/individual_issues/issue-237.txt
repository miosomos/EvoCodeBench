  :param coordinate_order: String, indicating whether the sample locations are in 'xyz' or 'zyx' order. Default is 'xyz'.
  :param method: String, specifying the interpolation method to use. Must be either 'TRILINEAR' for trilinear interpolation or 'NEAREST' for nearest neighbor interpolation. Default is 'TRILINEAR'.
  :param half_pixel_center: Bool, determines if half-pixel centering is used, which affects the calculation of sample locations. Default is False.
  :return: A tensor of shape [D, ..., C] containing the resampled values. This tensor contains the output volume data after resampling at the specified locations.

  """
