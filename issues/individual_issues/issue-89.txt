    Input-Output Arguments
    :param tq: Tensor. The query times at which to evaluate the step function.

    :param outside_value: Numeric, optional. The value to return for query times that exactly match a step change time. Defaults to 0.
    :return: Tensor. The interpolated or outside values of the step function at the query times.
    """
