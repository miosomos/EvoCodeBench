    :param options: Optional[Options], default to None. Additional options for the chat request.
    :param keep_alive: Optional[Union[float, str]], default to None. Specifies the keep-alive parameter for the chat session. Can be a float representing seconds or a string.
    :return: Union[Mapping[str, Any], AsyncIterator[Mapping[str, Any]]]. If 'stream' is False, returns a single ChatResponse as a mapping. If 'stream' is True, returns an asynchronous generator of ChatResponse mappings.
