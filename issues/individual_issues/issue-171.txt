    def lookup(self, string):

        """
        The lookup function checks if a given string is possibly in the Bloom Filter by using its hash functions to generate indices and then checking if all bits at these indices are set in the filter's bit array. If any bit is not set, it returns False, indicating the string is definitely not in the filter. Otherwise, it returns True, indicating the string might be in the filter (with a possibility of false positives).

        Input-Output Arguments
        :param self: BloomFilter. An instance of the BloomFilter class. It uses the instance's hash_functions, hash_count, size, and bit_array attributes to perform the lookup.
        :param string: str, The string to check for presence in the Bloom Filter. It is used as input to the hash functions to generate indices in the bit array.
        :return: bool, Indicates whether the string is possibly in the Bloom Filter (True) or definitely not in the Bloom Filter (False).
        """
