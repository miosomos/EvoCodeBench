  This function calculates 3D camera rays given 2D pixel coordinates, camera inverse intrinsics, and extrinsics. It supports optional distortion correction, different camera projection types (e.g., fisheye, panoramic), and can work with either numpy or jax.numpy for computations. The function is vectorized to handle arrays of pixel coordinates and camera parameters, and it computes ray origins, directions, normalized view directions, ray differential radii, and image plane coordinates.

  Input-Output Arguments
  :param pix_x_int: int array, shape SH, the x coordinates of image pixels, used as part of the input to compute ray directions.

  :param camtoworlds: float array, broadcastable to SH + [3, 4], the extrinsics of the cameras, used to transform camera coordinates to world coordinates.

  :param xnp: module, either numpy or jax.numpy, the numerical library used for computations, allowing the function to be used with different backends.

  :return: A tuple containing:
           - origins: float array, shape SH + [3], the origin points of the rays in world coordinates.
           - directions: float array, shape SH + [3], the direction vectors of the rays in world coordinates.
           - viewdirs: float array, shape SH + [3], the normalized direction vectors of the rays.
           - radii: float array, shape SH + [1], the differential radii of the rays, useful for mip-NeRF cones.
           - imageplane: float array, shape SH + [2], the xy coordinates on the image plane, representing the projection of pixel coordinates in world space.
